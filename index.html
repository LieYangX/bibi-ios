AI 对话

DeepSeek 驱动，SSE 流式回复与多轮 function calling 自实现。「昨天咖啡花了多少」——它边想边查边答。

灵魂设定、用户画像与长期记忆三类记忆库，「记住我每个月一号发工资」——它真的会记住。

✉

主动提醒

定时任务到期、该记账了，智能体会主动开口；多本地用户各自独立，互不打扰。

手机 ↔ 桌面端

手机随身，电脑算账——两端通过局域网无缝协作

笔笔 · iOS 端
  • NetServiceBrowser 自动发现电脑（也可手动输入 IP 直连）
  • 6 位配对码换取 Token，Keychain 安全保存
  • 电脑工具与本地工具合并注入 function calling
  • 心跳检测 + 指数退避自动重连
⇄ 局域网 Bonjour 发现 · 配对 · HTTP 调用
笔笔 · 桌面端
  • Tool Server：Express HTTP（端口 19878）+ Bonjour 广播
  • 配对码认证（300 秒有效），Bearer Token 鉴权
  • 动态导出已启用 Skill 的工具清单（含 JSON Schema）
  • 配对设备管理：查看与撤销
